- disco - party lights (all lights animated and color changing and spread changes - each independently settable with timing selections).  pick between a list if colors user can select or rainbox (moves between a bunch of random colors), with color phase change duration, duration to stay at each color, easing function for the transitions, similar options for the animation of the actuation value, and for the light angle spread values.  player should be able apply any combination of these aspects in the animation, and pick either an individual light subpart to attach the runtime state to, or, all lights on a craft.  (some lights cant animate, so just dont animate those ones)
- graffiti - spray mode .. have a setting for # of millis between spray, but when mouse is held down, keep applying decals at that tick rate
- humble-arteest - can we have a point-and-click raycast option to paint a clicked subpart mesh?  would this be for all subparts of that mesh type or individual instances? if we can target individual subpart mesh instances for paint specifically, that's preferred and then give the user the option of per-part or per-mesh texture change.  if per-instance is not possible, then just do the per-mesh change capability.
