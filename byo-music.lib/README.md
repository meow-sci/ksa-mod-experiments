# BYO Music library (nonshipping experiment)

`MusicPlayer` looks up a KSA `MusicPlayList` by asset ID and starts it through `PlayMusic`. This project is outside the Unscience shipping solution and has no workspace feature adapter. It is retained with the separate music experiment for reference; it is not distributed by the Unscience host.

See [project index](../REPOSITORY_INDEX.md) and [music integration scope](../scope/standalone-mods.md).
