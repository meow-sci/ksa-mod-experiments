Other files in this directory are dated proposals, implementation records or game-upgrade investigations. Use [REPOSITORY_INDEX.md](../REPOSITORY_INDEX.md), feature READMEs and [scope/FULL_SCOPE.md](../scope/FULL_SCOPE.md) for current ownership and status. Preserve historical findings rather than rewriting old plans as if they described the current tree.
