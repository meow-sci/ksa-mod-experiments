# Pebbles implementation record — 2026-09-05

The user approved implementation after the source investigation and Workshop proposal. Pebbles is now the 26th bundled Unscience feature library. Current behavior and ownership are in [the feature README](../pebbles.lib/README.md), [runtime integration](../scope/ground-clutter.md) and [preview integration](../scope/ground-clutter-preview.md).

Implemented scope follows the proposal's core body/ecotype/variant phases plus the requested Workshop: exact per-body capture and scoped overrides, five-LOD component meshes and material slots, bulk replacement preserving placement identities, native biome masks and placement controls, source-color adaptation, original/none/custom collision recipes, private GPU preview and detached collider editing. Feature-defined Harmony demand and safe-frame replacement/restoration follow the current workspace conventions. Main authoring and applied Live State are separate.

The Workshop uses studio lighting and ImGui collider outlines over a privately rendered mesh. Outlines are an x-ray authoring overlay, not a physics simulation or a terrain-lighting reproduction. The preview uses conservative GPU completion waits when changed. Primitives are built into native Bepu shapes only during explicit Apply at the runtime boundary.

The original proposal explicitly marked exact biome-local appearance routing, new native placement shader parameters, and a separate physics test sandbox as additional design phases. Those optional extensions are not implemented. Native biome masks operate at ecotype scope. Clutter slot order/count is preserved; changing the schema's object identities is rejected. Convex hull authoring uses a selected mesh rather than an automatic mesh-decomposition tool.

Managed validation covers recipe/camera persistence, numeric constraints and Workshop geometry/manipulators/history. Both preview shaders are compiled separately as SPIR-V. The full solution, contract executable and repository boundary/documentation checks are required before delivery. Native KSA acceptance remains outstanding: the local managed environment does not establish Vulkan rendering, Harmony transpiler execution, collision/exclusion correctness or scene-change teardown.
